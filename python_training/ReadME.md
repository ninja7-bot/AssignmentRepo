# Python Fundamentals Assignment

This repository contains solutions for the Python Fundamentals training assignment. The exercises cover core Python concepts ranging from basic syntax to Object-Oriented Programming (OOP).

## Topics Covered

### Introduction to Python

* Printing output
* Python version checking
* User input and formatted output

### Variables and Data Types

* Integer, float, string, and boolean data types
* Type checking
* Swapping variables
* Basic arithmetic operations

### Operators and Conditional Statements

* Even or odd number check
* Positive, negative, or zero check
* Largest of three numbers
* Grade calculation
* Leap year validation

### Loops

* Number sequences
* Multiplication tables
* Factorial calculation
* Number reversal
* Prime number checking

### Functions

* Square calculation
* Palindrome checking
* Maximum value from a list
* Functions with default parameters

### Modules

* Using built-in modules such as `math` and `random`
* Creating and importing custom modules

### Data Structures

* Lists
* Tuples
* Sets
* Dictionaries

### File Handling

* Creating and writing files
* Reading file contents
* Appending data
* Copying files
* Searching text within files

### Object-Oriented Programming (OOP)

* Classes and objects
* Constructors
* Inheritance
* Encapsulation
* Polymorphism
